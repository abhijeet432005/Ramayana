# Ramayana: immersive horizontal WebGL story
Next.js 16, React 19, Three.js (GLSL), GSAP ScrollTrigger, Lenis

    npm install && npm run dev

## v4
- **Horizontal scroll.** Wheel, trackpad, touch and arrow keys / space all move the story left to right. Lenis (horizontal) feeds ScrollTrigger (`horizontal: true`).
  Smoothness: Lenis runs first in the shared `gsap.ticker`, then ScrollTrigger, then the WebGL render, so DOM and canvas always see the same scroll position in a frame.
- **Light theme only.** Dark mode, the theme toggle, language toggle and all narration (Web Speech, voice-over mp3 hooks) are gone.
- **Motif background.** `public/art/motifs.svg` is a 4x4 atlas of 16 silhouettes (banyan, palm, deer, elephant, peacock, house, temple, lotus, birds, cow, monkey, fish, diya, bow and arrow, mountains, hut).
  The background shader tiles them faintly on the paper, drifting slower than the page. Near the cursor each motif wakes up in colour, scales slightly, sways and gets a soft halo.
  Edit `scripts/make_motifs.py` and run `python3 scripts/make_motifs.py` to change the drawings.
- **No water ripples** anywhere (background and artwork). Artwork hover is now a push-in toward the cursor with a slight chromatic split.
- **Sound (calm edition)**: tanpura, a slow breathy bansuri, a soft pad, distant bells, quiet wind/water/birds. No drums or percussion, no conch, nothing sudden. All instruments sit in a long reverb hall; scroll only adds a whisper of wind.
  dhol (dagga + tilli, patterns and rolls that grow with the story), manjira, ghungroo, temple bells, shankh (conch) and wind.
- Optional: drop anime clips at `public/video/<id>.mp4` (muted, looping). They replace the SVG art automatically.

## v10 (presentation build)

- **Alive scene**: floating diya embers that sway, twinkle, avoid the cursor and streak with scroll speed; a slow breathing glow in the chapter colour; artwork gently floats.
- **Robustness**: loader never gets stuck (8 s failsafe); if WebGL is unavailable the flat SVG art is shown instead; reduced-motion respected.
- Polished gate, key hints on the hero, closing diya on the final screen, favicon and share metadata.
- Note: `next/font/google` needs internet on first build/dev run.
